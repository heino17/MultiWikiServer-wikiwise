https://www.npmjs.com/package/@mws/wikiwise

This is the init package for the MultiWikiServer-wikiwise fork. npm runs it when
someone executes `npm init @mws/wikiwise@latest <folder-name>`: it creates the
folder, copies the instance configuration into it and installs the fork from npm.

The package `@tiddlywiki/mws` on npm is the upstream project, not this fork.
